Backup

A backup is one file holding everything on this device: products, deliveries, sales, removals and shop details. If this device is lost or the app is deleted, the backup is the only copy.

File–

On the iPad, Save the file opens the share sheet: choose Save to Files (iCloud Drive is best), or send it to yourself on LINE or email. On the Windows computer the file goes to Downloads; copy it to a USB stick or Google Drive. The file holds all your sales, so keep it private.

Check or load a backup

Pick a backup file to see what is inside and whether it is complete. Checking never changes anything. Loading is only offered on an empty till, so nothing can be overwritten.
